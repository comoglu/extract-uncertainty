i# SeisComp Uncertainty Extractor

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A Python tool for extracting earthquake location uncertainty parameters from SeisComp XML files.

## Overview

SeisComp Uncertainty Extractor is a command-line tool that parses SeisComp XML files to extract comprehensive uncertainty information for seismic events. The tool retrieves coordinates, origin time, depth, and various uncertainty metrics including error ellipses, confidence ellipsoids, and quality parameters.

This tool is particularly useful for seismologists and researchers who need to analyze location uncertainty in earthquake catalogs generated by SeisComP systems.

## Features

- Extract comprehensive uncertainty information from SeisComp XML files
- Support for multiple SeisComp schema versions and namespaces
- Export data to CSV format for easy analysis
- Extract confidence ellipsoid parameters
- Retrieve quality metrics (azimuthal gap, phase counts, etc.)
- Support for preferred and non-preferred origins
- Detailed error handling and reporting
